# YTM Mini

유튜브 뮤직을 항상 위에 뜨는 작은 창으로 띄우는 크롬 확장.
Document Picture-in-Picture API로 앨범아트와 재생 컨트롤만 따로 떼어냅니다.
재생 자체는 원래 탭에서 그대로 돌아가기 때문에 로그인·DRM은 브라우저가 처리하고,
확장은 권한을 하나도 요구하지 않습니다.

## 설치

1. 이 저장소를 클론합니다.
2. `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드**로 저장소 폴더를 선택합니다.

Chrome 또는 Edge 116 이상이 필요합니다.

## 사용

music.youtube.com에서 우하단 **미니** 버튼을 누르거나 `Alt+P`를 누릅니다.

미니 창 안에서:

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `←` `→` | 이전 곡 / 다음 곡 |

진행 바를 클릭하면 해당 위치로 이동합니다.

## 구조

- `manifest.json` — music.youtube.com에만 붙는 콘텐츠 스크립트 하나
- `content.js` — 상태 읽기, 미니 창 렌더링, 컨트롤 전달

재생 상태와 시간은 페이지의 `<video>` 엘리먼트에서 직접 읽고,
곡 정보는 플레이어 바 DOM에서 가져옵니다. 셀렉터는 `content.js` 상단
`SEL` 객체에 모여 있어서 유튜브 뮤직이 마크업을 바꾸면 그 부분만 고치면 됩니다.

`requestWindow()`는 사용자 조작 직후에만 호출할 수 있습니다. 확장 아이콘 클릭은
메시지를 거치면서 user activation이 끊기기 때문에, 페이지 안에 버튼을 심고
키 입력을 직접 받는 방식으로 창을 엽니다.
